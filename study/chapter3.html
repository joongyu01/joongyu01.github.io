LAST 10 MINUTES

3장 마지막 핵심 여덟 가지

3장 강의 기반 복습용입니다. 전체 시험 범위 1~3장은 핵심정리에서 이어 보세요.

01 / SEQ·ACK

ACK는 다음으로 받을 바이트 번호

SEQ 700에서 80B 수신 → 700~779 → ACK 780. 양방향 SEQ 공간은 독립이다.

데이터 +길이 / SYN·FIN +1 / 순수 ACK +0.
02 / 교수자 예제

마지막 C→S: SEQ 2202, ACK 3202

C 초기 2000, S 초기 3000. 각각 데이터 200B, SYN·FIN 각각 1. C 2000+202, S 3000+202.

종료 중간 ACK와 FIN은 한 세그먼트로 합칠 수 있음.
03 / 누적 ACK

중간이 비면 그 번호에서 기다림

100~499 수신, 500~599 손실, 600~899 버퍼 → ACK 500. 빈칸 복구 후 ACK 900.

SACK는 뒤쪽에 따로 받은 블록 정보를 추가로 알림.
04 / 헤더

Data Offset ×4 = TCP 헤더 B

8→32B, 옵션+패딩 12B. 기본 20B+옵션 3B+패딩 1B=24B → Offset 6.

TCP 최소 20B / UDP 고정 8B / MSS는 데이터 크기.
05 / 윈도

min(rwnd,cwnd) − 미확인 데이터

8000B, 5000B, 미확인 2000B → 추가 3000B. 창 시작 500·크기 800 → 500~1299.

rwnd 수신 버퍼 / cwnd 네트워크 혼잡.
06 / 손실 복구

중복 ACK와 타임아웃을 구분

전형적인 빠른 재전송: 최초 ACK 이후 중복 ACK 세 개. RTT는 왕복 시간, RTO는 재전송 대기 기준.

순서 뒤바뀜 등도 가능하므로 손실 신호로 추정하는 것.
07 / 혼잡 그래프

강의 모델: 배증 → 선형 증가

초기 1, 임계값 16: 1→2→4→8→16→17→18. 그림의 중복 ACK 감소는 약 절반, 타임아웃은 1부터.

문제의 알고리즘·초기값 우선. 모든 TCP의 고정 동작은 아님.
08 / QUIC

스트림별 순서와 Connection ID

다른 스트림의 불필요한 HOL을 줄이고 주소 변경 시 연결을 이어갈 수 있다. 0-RTT는 조건이 맞는 재접속 등에서 가능.

동일 스트림 손실과 연결 단위 혼잡 영향까지 없애지는 않음.
학습 근거와 확인 범위

3장 교안, 교수자 TCP 보충자료, 확보한 강의 영상 자막을 바탕으로 작성한 자체 복습 문제입니다. 강의 영상의 시간은 영상 시작 기준이며 각 해설에서 해당 근거를 확인할 수 있습니다. 자막 오인식은 교안과 계산으로 교정했습니다.

교재 연습문제 원문·번호·공식 답안과는 다릅니다. 문제의 수치 변형과 선택지는 새로 작성했습니다. TCP 종합 문제는 교수자 보충자료의 수치를 사용했습니다.

기술 표현 대조: TCP · 혼잡 제어 · QUIC · HTTP 캐시. 이는 출제 확정의 근거가 아닙니다.

학습 기록은 장별로 이 브라우저에 저장되며 기기 간 동기화는 없습니다.
